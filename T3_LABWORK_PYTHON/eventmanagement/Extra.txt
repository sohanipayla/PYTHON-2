Step 1: Terminal Commands for Setup
django-admin startproject musicplayer

To create the app inside project: python manage.py startapp findmusic

Step 2: Database Model Structure (models.py)

class Music(models.Model):
    song = models.CharField(max_length=200)
    artist = models.CharField(max_length=200)
    album = models.CharField(max_length=200)
    year = models.IntegerField()

 Step 3: Database Migration Commands
 python manage.py makemigrations

To apply changes to SQLite database: python manage.py migrate

Step 4: Superuser Creation Command 
python manage.py createsuperuser

Step 5: View Logic for Data Extraction (views.py)

def display_music(request):
    all_songs = Music.objects.all()
    context = {
        'songs': all_songs
    }
    return render(request, 'musicfind.html', context)
